Try the endpoint

The dynamic page is available at / and /index.html. CSS is served separately. All other HTTP methods return 405.

curl -i "http://127.0.0.1:{{ server_port }}/?name=Ada"

HTTP/1.1 200 OK
Server: clm net/web
Content-Type: text/html; charset=utf-8

Refresh to see a new request ID, timestamp and counter. Hard refresh to recompile your edited index.html.

How the app is built

In main.c follow the numbered steps: load assets, compile the template, start networking, register routes, bind a context, and render.

clm_net_web clm_http_utils clm_template clm_async_pool

HTTP/2, HTTP/3, and a general-purpose static-file service remain outside this example.
