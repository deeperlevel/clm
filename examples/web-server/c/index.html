Congratulations! This page is being served by CLM net/web, an HTTP/1.1 server built on Cross Language Modules. Small, reusable components work together to handle connections, parse HTTP requests, route traffic, and send responses.

Try the endpoint

This example serves one cached index.html file from two GET routes. Other methods return 405 Method Not Allowed.

curl -i http://127.0.0.1:8080/

HTTP/1.1 200 OK
Server: clm net/web
Content-Type: text/html; charset=utf-8

The command assumes the default port, 8080. The response also includes generated headers.

What's next?

CLM net/web starts with HTTP/1.1. The broader roadmap includes more efficient streaming and connections, an HTTP client, and future HTTP/2 and HTTP/3 protocol support.

HTTP body streaming HTTP client / ProxyPass HTTP/2 HTTP/3 + QUIC

These roadmap features are not enabled by this example.
